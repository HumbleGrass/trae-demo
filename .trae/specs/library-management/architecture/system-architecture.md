## 一、系统概述

图书馆借阅管理系统是一个为省级图书馆设计的综合管理平台，提供书籍管理、会员管理、借阅管理、预约管理、费用管理等核心功能。

## 三、模块划分

### 3.1 功能模块

| 模块 | 功能 | 权限 |
|------|------|------|
| Auth | 登录、注册、Token 管理 | 公开 |
| Books | 书籍 CRUD、搜索、库存管理 | Admin |
| Members | 会员 CRUD、额度管理 | Admin |
| Borrow | 借阅、归还、续借 | Admin/User |
| Reservations | 预约、取消、通知 | Admin/User |
| Fines | 费用计算、缴纳 | Admin/User |
| Reports | 统计报表 | Admin |
| Analytics | 数据分析、推荐 | Admin/User |
| Settings | 系统配置、字典管理 | Admin |

## 六、安全架构

### 6.1 认证流程

```
┌─────────┐     ┌─────────┐     ┌─────────┐
│  用户   │────▶│  登录   │────▶│ JWT签发 │
└─────────┘     └─────────┘     └─────────┘
                                     │
                                     ▼
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 访问API │◀────│ 携带JWT │◀────│ 存储JWT │
└─────────┘     └─────────┘     └─────────┘
     │
     ▼
┌─────────┐     ┌─────────┐
│验证守卫 │────▶│ 角色检查│
└─────────┘     └─────────┘
```

### 6.2 安全措施

| 层级 | 安全措施 |
|------|----------|
| 传输层 | HTTPS、TLS 1.3 |
| 认证层 | JWT + Refresh Token、密码 bcrypt 加密 |
| 授权层 | RBAC 角色权限控制 |
| 应用层 | 参数验证、SQL 注入防护、XSS 防护 |
| 数据层 | 敏感数据加密、SQL 审计 |
