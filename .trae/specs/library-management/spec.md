## 一、产品概述

### 1.1 产品背景

为国家省级图书馆开发一个图书借阅管理系统，提供高效、安全、便捷的借阅服务。系统需要处理书籍流转、会员管理、逾期处理等核心业务，提高运营效率，减少人工错误，提升读者体验。

### 1.2 产品目标

| 目标 | 描述 | 衡量指标 |
|------|------|----------|
| 提高效率 | 自动化借阅流程，减少人工操作 | 借阅处理时间 < 30秒 |
| 减少错误 | 系统自动校验，避免人为失误 | 错误率 < 0.1% |
| 提升体验 | 便捷的预约、续借、查询服务 | 用户满意度 > 90% |
| 数据洞察 | 提供借阅统计和数据分析 | 报表生成时间 < 5秒 |

### 1.3 用户角色

| 角色 | 描述 | 主要功能 |
|------|------|----------|
| 管理员 | 图书馆工作人员 | 书籍管理、会员管理、借阅管理、统计报表 |
| 用户 | 注册会员 | 书籍查询、个人借阅、预约、费用查询 |

## 二、功能需求

### REQ-001: 用户认证

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 模块 | Auth |
| 描述 | 用户通过用户名密码登录系统，获取访问权限 |

**验收标准**：
- [ ] 用户可以使用正确的用户名密码登录
- [ ] 登录成功后返回 JWT Token
- [ ] 错误密码返回 401 错误
- [ ] Token 有效期内无需重复登录

**关联任务**：TASK-002

|------|------|

### REQ-005: 借阅管理

| 属性 | 内容 |
|------|------|
| 优先级 | P0 |
| 模块 | Borrow |
| 描述 | 处理书籍借阅、归还、续借操作 |

**验收标准**：
- [ ] 借阅前验证书籍库存 > 0
- [ ] 借阅前验证会员借阅额度未超限
- [ ] 自动设置归还日期（借阅日期 + 14天）
- [ ] 续借仅限一次，延长 7 天
- [ ] 归还时自动计算逾期费用

**关联任务**：TASK-005

## 四、业务规则

### 4.1 借阅规则

| 规则 | 描述 |
|------|------|
| 借阅上限 | 每位会员最多同时借阅 5 本书 |
| 借阅期限 | 默认 14 天 |
| 续借规则 | 仅限续借 1 次，延长 7 天 |
| 逾期费用 | 0.5 元/天/本 |

### 4.2 预约规则

| 规则 | 描述 |
|------|------|
| 预约条件 | 仅允许预约库存为 0 的书籍 |
| 预约上限 | 每位会员最多预约 3 本书 |
| 预约排序 | 按预约时间先后排序 |

### 4.3 权限规则

| 角色 | 权限范围 |
|------|----------|
| Admin | 书籍管理、会员管理、借阅管理、预约管理、费用管理、统计报表、系统设置 |
| User | 书籍查询、个人借阅、个人预约、个人费用查询 |
