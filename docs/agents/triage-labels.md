# 分诊标签

技能内部使用五个标准分诊角色来沟通，本文件将这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义                                   |
| -------------------------- | ---------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`   | 维护者需要评估这个 issue                |
| `needs-info`               | `needs-info`     | 等待报告者补充更多信息                  |
| `ready-for-agent`          | `ready-for-agent` | 已充分说明，可交给自动化代理执行        |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                           |
| `wontfix`                  | `wontfix`        | 不会处理                               |

当技能提到某个角色（例如「打上 ready-for-agent 分诊标签」）时，使用本表中对应的标签字符串。

如需调整，请编辑右侧列以匹配实际使用的标签。
