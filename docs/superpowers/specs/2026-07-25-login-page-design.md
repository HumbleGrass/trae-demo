# 工作人员登录页 Notion 风格重设计

## 背景

当前登录页已具备完整的登录、注册、找回密码和快捷登录入口，但视觉结构仍以居中悬浮卡片为主，并保留了较多历史赛博风格命名和装饰代码。此次改造面向图书馆工作人员，将页面迁移为安静、清晰、适合高频使用的 Notion 风格工作台入口。

本次属于样式迁移，不是功能重构。

## 目标

- 让工作人员能够快速识别系统、定位表单并完成登录。
- 使用 `DESIGN.md` 定义的暖纸张画布、近黑文字、单一结构蓝和深靛蓝品牌区。
- 在桌面、平板和手机上保持稳定的信息层级与可操作性。
- 同步统一注册与找回密码弹窗的视觉语言。
- 移除粒子、网格、扫描线、全息、霓虹和高亮渐变等旧视觉表达。

## 非目标

- 不修改 API、路由、权限、Pinia store 或数据请求方式。
- 不修改登录、注册和找回密码的业务流程。
- 不修改组件 props、外部调用方式或表单校验规则。
- 不新增第三方依赖、登录方式或账号能力。
- 不重构登录页之外的业务页面。

## 视觉方向

采用已确认的 B 方案“编辑式分栏”。

页面使用暖灰纸张色作为全屏画布，中央放置一个克制的双栏工作区。工作区以边框和极轻阴影建立层级，不使用嵌套卡片。左栏是深靛蓝品牌页，右栏是白色表单页。

左侧品牌页包含：

- “知阅阁”标识与系统名称。
- 现有英文系统名称。
- 低对比度的书页、索引或借阅轨迹装饰；装饰不承担交互和信息传达。

右侧表单页包含：

- 现有欢迎文字。
- 用户名与密码字段。
- 记住密码与忘记密码入口。
- 主登录按钮及现有加载状态。
- 快捷登录入口、注册入口和安全提示，降为次要层级但保持可见和可操作。

## 布局与响应式

### 桌面端

- 工作区最大宽度约 `1040px`，最小高度约 `620px`。
- 左右栏比例约为 `42% / 58%`。
- 表单内容限制在可读宽度内，不随右栏无限拉伸。
- 页面允许在低高度窗口自然滚动，任何内容不得被固定区域遮挡。

### 平板端

- 保持分栏，比例收敛到约 `38% / 62%`。
- 缩小品牌文案字号和工作区内边距。
- 快捷登录和辅助入口保持稳定点击区域。

### 手机端

- 在 `768px` 以下切换为单栏。
- 品牌区位于顶部并压缩为紧凑横向页眉，不占据完整首屏。
- 表单区位于下方，保持至少 `16px` 水平边距。
- 页面使用自然滚动，不强制把全部内容压进单屏。
- 所有主要点击目标高度不小于 `44px`。

## 组件与状态

### 输入框

- 沿用 Element Plus 输入框和现有 `v-model`、校验及密码显示能力。
- 使用 `4px` 圆角、白色表面、灰色细边框。
- 聚焦状态使用单一结构蓝和轻量 focus ring。
- 错误状态继续由现有表单规则和 Element Plus 呈现。

### 主按钮

- 使用 `--color-primary` 作为唯一结构性强调色。
- 使用胶囊形圆角，保留现有禁用与加载状态。
- 保留现有按钮文案和提交行为。

### 次要操作

- 忘记密码和注册入口使用文本链接。
- 快捷登录按钮使用统一的描边图标按钮，不引入新的登录逻辑。
- 现有安全提示保留，但降低对比度。

### 弹窗

- 注册与找回密码继续使用现有 Element Plus Dialog。
- 弹窗使用现有全局主题变量，不通过全局 `!important` 覆盖。
- 字段、校验、按钮行为、关闭规则与宽度语义保持不变。
- 手机端宽度使用视口约束，避免超出屏幕。

## 动效与无障碍

- 页面进入时只使用一次轻微淡入和上移，时长不超过 `300ms`。
- 输入、按钮和链接的交互反馈控制在 `150ms` 至 `200ms`。
- `prefers-reduced-motion: reduce` 下禁用非必要动画。
- 表单标签保持可见，不以 placeholder 代替标签。
- 键盘焦点必须清晰，回车提交行为保持不变。
- 文字、边框和控件状态需满足可辨识的对比度。

## 技术边界

- 主要修改范围为 `frontend/src/views/login/index.vue`。
- 使用现有 `frontend/src/styles/design-tokens.scss` 变量层。
- Element Plus 的通用主题继续由现有 SCSS 编译覆盖提供，不添加全局 `!important`。
- 模板只调整 class 和内联样式引用，不修改展示文案、组件绑定或事件。
- 脚本仅删除不再需要的纯装饰逻辑，登录相关逻辑保持原样。
- 不使用 `any`，不新增无类型数据结构。

## 验证标准

- `npm run lint` 通过；若仓库已有与本次无关的错误，需单独记录。
- `npm run build` 通过。
- 在真实浏览器验证桌面、平板和手机视口。
- 验证用户名、密码、密码显示、记住密码、回车提交和登录按钮状态。
- 验证注册弹窗、找回密码弹窗的打开、关闭和响应式布局。
- 检查页面无横向滚动、内容重叠、文本溢出和布局跳动。
- 检查浏览器控制台无本次改动引入的错误。

## 验收结果

完成后，登录页应呈现为一个安静、可信、有明确“知阅阁”品牌记忆的工作人员入口，同时所有现有功能和外部契约保持不变。
