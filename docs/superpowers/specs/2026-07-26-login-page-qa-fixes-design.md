# 登录页 QA 问题修复设计

## 背景

`agent-browser` 对登录页的复测发现五项问题：快速登录入口没有行为反馈、主登录表单绕过前端必填校验、两个文字链接的移动端触控区域不足、页面没有实际加载 Inter 字体、底部安全提示对比度不足。

本次改动属于样式迁移与局部缺陷修复，不改变 API、路由、权限、Pinia 状态结构或组件外部接口。

## 目标

- 删除微信、QQ、邮箱快速登录入口及其分隔区。
- 主登录表单在用户名或密码无效时阻止 API 请求，并显示 Element Plus 字段错误。
- “忘记密码”和“立即注册”保持文本链接视觉，但在移动端提供至少 44px 高的触控区域。
- 全项目统一加载并使用自托管的开源 Inter 字体，作为 `DESIGN.md` 指定的 NotionInter 替代字体。
- 将底部安全提示调整为满足普通文字可读性的颜色。

## 实现设计

### 登录表单校验

将用户名和密码字段从普通容器改为带对应 `prop` 的 `el-form-item`。保留现有 `rules`、`formRef.validate`、登录方法、请求模式和状态管理。字段结构只负责让 Element Plus 建立模型字段与校验规则的关联。

### 快速登录入口

从模板中移除“快速登录”分隔线和三个社交登录按钮，同时删除只服务于这些元素的样式。注册入口保留，间距调整为直接承接主登录按钮后的次要操作。

### 文字操作

将“忘记密码”和“立即注册”改为 `type="button"` 的语义化按钮，避免无 `href` 的伪链接。按钮继续使用蓝色文本、透明背景和紧凑视觉，但通过内边距与最小高度提供 44px 触控区域，保留现有弹窗开关方式。

### 全局字体

新增 `@fontsource/inter` 依赖，在应用入口加载所需的 400、500、600、700 字重。字体令牌统一为 `"Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。所有使用基础、技术、展示和等宽兼容别名的组件会通过现有 CSS 变量继承 Inter，不逐页覆盖字体。

### 文字对比度

底部安全提示从 `--text-placeholder` 调整为 `--text-muted`。保持白色背景、发丝分隔线和现有布局，不引入额外强调色。

## 测试设计

- 扩展登录页单元测试，验证快速登录文案与按钮已移除。
- 验证用户名和密码均存在带 `prop` 的 `el-form-item`。
- 挂载登录组件，空表单点击登录后断言登录 action 未调用且出现必填提示。
- 验证两个文本操作为按钮，并具有至少 44px 的触控高度样式。
- 验证字体入口加载 Inter 字重，字体令牌不再声明不存在的 NotionInter。
- 验证底部提示使用 `--text-muted`。
- 运行单元测试、lint、生产构建。
- 使用 `agent-browser` 在 1440x900、768x1024、390x844 视口复测布局、空表单、弹窗和控制台。

## 非目标

- 不调整桌面 42/58 分栏构图。
- 不新增任何第三方登录能力。
- 不修改注册流程、认证 API、路由跳转或用户状态管理。
- 不重构登录页以外的业务组件。
